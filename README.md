# Walia Code

Hybrid CLI autonomous coding agent (opencode + aider). Powered by qwen3-coder:14b and Big Pickle.

## Features
- Big Pickle first, qwen3-coder:14b via Ollama fallback
- Approval gate for shell/SQL/email/file ops
- Manus-style planning (task_plan.md, notes.md, deliverable.md)
- System shell access (CMD/PowerShell)
- SQL server access
- Email sending with approval
- Sub-agents
- Git-aware autonomy
- Config system (~/.walia/config.json)
- Pinokio ready

# Privacy-Aware Assistant Features

## Awareness
- Network scanning awareness
- App behavior analysis
- File inspection for suspicious patterns
- Location awareness (with permission)
- System/hardware info (with permission)
- Notification reading (with permission)
- Contacts awareness (with permission)
- Google account context (with permission)

## Protection
- Warns about phishing/malicious apps
- Explains risks in simple words
- Suggests safe alternatives
- Privacy-first - asks permission before accessing
- Can explain why something looks suspicious
- Helps user stay safe without scaring

## Smart Suggestions
- Suggests replies to messages/notifications
- Gives casual advice (like flirting tips) if asked
- Context-aware without being creepy
- Always respects boundaries
- User can disable any feature

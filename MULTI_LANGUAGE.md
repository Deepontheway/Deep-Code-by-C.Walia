# Multi-Language Support

Walia Code supports and can use:
- TypeScript/JavaScript (Node)
- Python (with venv/conda/anaconda)
- C++ (CMake, g++, MSVC)
- C# (dotnet)
- Java (Maven/Gradle)
- HTML/CSS
- Go, Rust, Kotlin (as needed)
- Godot GDScript
- SQL
- PowerShell/Bash

Auto-detects runtimes and installs if missing with approval.

# Feature Recommendations

## Core Enhancements
- MCP support (Model Context Protocol) - connect to external tools
- Browser automation with Playwright (already planned)
- File tree viewer in CLI
- Multi-session support with history
- Project context indexing (embeddings)
- Diff viewer with syntax highlighting
- Auto-commit with smart messages

## Safety
- Sandboxed mode toggle
- Command blacklist/whitelist
- Path restrictions enforcement
- Session logging
- Dry-run mode

## UX
- /model command to switch models
- /plan to view/edit task plan
- /config to edit config
- /history to view approvals
- Theme support
- Progress indicators
